# 🛒 Amazon Sales Performance Analysis using Excel

## 📌 Project Overview

**Amazon Sales Performance Analysis** is an Excel-based data analytics project designed to analyze one month of Amazon order-level sales data.

The project focuses on understanding **sales performance, product and category trends, customer locations, payment methods, and order status** using Microsoft Excel.

The analysis includes data cleaning, preprocessing, PivotTables, calculated fields, and an interactive dashboard to transform raw transactional data into meaningful business insights.

---

## 🎯 Business Problem

An Amazon seller has provided one month of transactional sales data and wants to understand the overall sales performance of the business.

The analysis aims to answer the following key business questions:

* Which products generate the highest total sales?
* Which product categories perform best?
* Which customer locations contribute the most sales?
* Which payment methods are most commonly used?
* What percentage of orders are delivered, cancelled, or pending?
* Which customers contribute the highest spending?
* What are the major sales trends and patterns?

The goal is to provide a clear and interactive Excel dashboard that can support better business decision-making.

---

## 🎯 Project Objectives

The main objectives of this project are to:

* Load and understand the Amazon sales dataset.

## 🔄 Project Methodology

### 1. Data Loading

The raw Amazon sales dataset was imported into Microsoft Excel.

The dataset was initially reviewed to understand:

* Number of records
* Column structure
* Data types
* Missing values
* Duplicate records
* Inconsistent values

---

### 2. Data Cleaning

The following data-cleaning activities were performed:

* Removed duplicate records.
* Checked and handled missing values.
* Standardized date formatting.
* Converted Price, Quantity, and Total Sales into appropriate number formats.
* Used `TRIM()` to remove unnecessary spaces.
* Used `PROPER()` to standardize text values where required.
* Standardized category names.
* Standardized customer location names.
* Checked for inconsistent order status values.
* Validated the Total Sales calculation.

### Total Sales Validation

The expected calculation is:

```text
Total Sales = Price × Quantity
```

---

### 3. Data Preprocessing

Additional fields were created where required for analysis.

#### Month

```excel
=TEXT(Date,"MMM")
```

This field helps analyze sales by month.

#### Day of Week

An optional Day of Week field can be created using:

```excel
=TEXT(Date,"DDDD")
```

#### Order Status Grouping

Order statuses were grouped into:

* Delivered
* Cancelled
* Pending

This makes it easier to analyze order fulfillment performance.

## 📈 Data Analysis

## 💡 Business Recommendations

Based on the analysis, the seller can consider the following strategies:

1. **Focus on high-performing products**
   Maintain sufficient inventory for products generating high sales.

2. **Strengthen top-performing categories**
   Promote successful categories through targeted offers and marketing campaigns.

3. **Improve low-performing locations**
   Analyze customer preferences and consider location-specific promotions.

4. **Monitor cancelled orders**
   Identify the major reasons for cancellations and take corrective action.

5. **Reduce pending orders**
   Improve order processing and fulfillment efficiency.

6. **Optimize payment options**
   Ensure the most preferred payment methods remain easily available to customers.

7. **Reward high-value customers**
   Consider loyalty offers or personalized promotions for customers with high spending.
